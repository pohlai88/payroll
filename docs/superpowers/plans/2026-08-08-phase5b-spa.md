# Phase 5B SPA — Clarity Payroll Product UI Shell + Pay-Run Workspace

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the full product SPA: company-first shell (sidebar, scope bar, ⌘K), pay-run workspace (totals strip with server-supplied variance, column-grouped employee grid, employee slide-over with line / payslip preview / derivation tabs), and employees screen — all on the Straits token system.

**Architecture:** Vite + React SPA under `src/web/`. Client-side routing via `wouter`. No global state library — `ScopeContext` + `AuthContext` via React context. Workspace data fetched by `src/web/api/payroll-api.ts` client. All UI facts sourced from the server workspace read model (Phase 5B-PREFLIGHT); no arithmetic in React components.

**Tech Stack:** React 18, TypeScript, Tailwind v4, shadcn/ui (pinned `4.16.2`), wouter, recharts, Straits token system, Biome (lint + format)

## Global Constraints

- Section tokens are **complete hex values** — use `var(--section-earning-fill)` in `style={{ background }}` or `className` inline styles. **Never** `hsl(var(...))`.
- `DeltaBadge` receives `VarianceDto` from the server — it **never** receives `(current, previous)` to compute. No arithmetic in any presenter component.
- Status colours (`status-ok`, `status-bad`) are applied **only** when the server explicitly classifies something as ok/bad. `direction: "UP"` is **not** good. `direction: "DOWN"` is **not** bad.
- PCB is **read-only** in Phase 5B — no inline input, no blur-to-save.
- Payslip preview is **English only** and rendered **light-only** using `--doc-*` tokens.
- Action buttons read `actionAvailability` flags from the server — the client never re-derives them.
- `MoneyCell` is the **only** money formatter — no `toLocaleString`, no manual `RM` prefix, no `toFixed(2)` in any other component.
- `NodePanel` renders `node.citation.displayText` — never performs rule-pack lookups.
- Install shadcn primitives via `npx shadcn@4.16.2 add <name>` — never re-init.
- New `npm` dependencies require explicit install: `wouter`, `recharts`.
- Biome (`npx biome check --write`) must pass before every commit.
- Typecheck (`npx tsc --noEmit`) must pass before every commit.

import { Tooltip, TooltipContent, TooltipTrigger } from "@/components/ui/tooltip";

interface MoneyCellProps {
  sen: number | null;
  notApplicable?: boolean;
  citationText?: string;
  className?: string;
}

function MoneyCell({ sen, notApplicable = false, citationText, className }: MoneyCellProps) {
  if (notApplicable) {
    return (
      <Tooltip>
        <TooltipTrigger asChild>
          <span className={cn("text-right tabular-nums text-muted-foreground cursor-default", className)}>
            —
          </span>
        </TooltipTrigger>
        <TooltipContent>
          {citationText ?? "Not applicable by statute"}
        </TooltipContent>
      </Tooltip>
    );
  }

  if (sen === null) {
    return (
      <span className={cn("text-right tabular-nums text-muted-foreground", className)}>
        —
      </span>
    );
  }

  const formatted = new Intl.NumberFormat("en-MY", {
    style: "currency",
    currency: "MYR",
    minimumFractionDigits: 2,
  }).format(sen / 100);

  return (
    <span className={cn("text-right tabular-nums", className)}>
      {formatted}
    </span>
  );
}

- [ ] **Step 3: Create `delta-badge.tsx`**

```tsx
import { ArrowDownIcon, ArrowRightIcon, ArrowUpIcon } from "lucide-react";

interface VarianceDto {
  previousSen: number | null;
  deltaSen: number | null;
  deltaBps: number | null;
  direction: "UP" | "DOWN" | "SAME" | "NO_PRIOR";
}

interface DeltaBadgeProps {
  variance: VarianceDto;
  className?: string;
}

function DeltaBadge({ variance, className }: DeltaBadgeProps) {
  if (variance.direction === "NO_PRIOR") {
    return (
      <span className="text-muted-foreground text-xs">—</span>
    );
  }

  if (variance.direction === "SAME") {
    return (
      <span className="inline-flex items-center gap-0.5 text-muted-foreground text-xs">
        <ArrowRightIcon className="size-3" />
        0%
      </span>
    );
  }

  const bps = variance.deltaBps ?? 0;
  const pct = (Math.abs(bps) / 100).toFixed(1);
  const Icon = variance.direction === "UP" ? ArrowUpIcon : ArrowDownIcon;

  // Neutral directional ink — not green/red, never status-ok/status-bad
  return (
    <span className="inline-flex items-center gap-0.5 text-foreground text-xs font-medium">
      <Icon className="size-3" />
      {pct}%
    </span>
  );
}

export { DeltaBadge };
export type { DeltaBadgeProps, VarianceDto };

import { createContext, useCallback, useContext, useMemo, useState } from "react";
import type { ReactNode } from "react";

type CompanyScope =
  | { mode: "all" }
  | { mode: "selected"; companyIds: string[] };

interface ScopeContextValue {
  scope: CompanyScope;
  reportingMonth: string;           // "YYYY-MM"
  setScope: (scope: CompanyScope) => void;
  setReportingMonth: (month: string) => void;
}

const ScopeContext = createContext<ScopeContextValue | null>(null);

function ScopeProvider({ children }: { children: ReactNode }) {
  const now = new Date();
  const defaultMonth = `${now.getFullYear()}-${String(now.getMonth() + 1).padStart(2, "0")}`;

  const [scope, setScope] = useState<CompanyScope>({ mode: "all" });
  const [reportingMonth, setReportingMonth] = useState(defaultMonth);

  const value = useMemo(
    () => ({ scope, reportingMonth, setScope, setReportingMonth }),
    [scope, reportingMonth]
  );

  return <ScopeContext.Provider value={value}>{children}</ScopeContext.Provider>;
}

function useScopeContext(): ScopeContextValue {
  const ctx = useContext(ScopeContext);
  if (!ctx) throw new Error("useScopeContext must be used within ScopeProvider");
  return ctx;
}

export { ScopeProvider, useScopeContext };
export type { CompanyScope, ScopeContextValue };

import { createContext, useCallback, useContext, useEffect, useMemo, useState } from "react";
import type { ReactNode } from "react";
import { payrollApi } from "@/web/api/payroll-api";

interface MeDto {
  id: string;
  email: string;
  role: string;
  companies: Array<{ id: string; name: string }>;
}

interface AuthContextValue {
  me: MeDto | null;
  loading: boolean;
  signOut: () => void;
}

const AuthContext = createContext<AuthContextValue | null>(null);

function AuthProvider({ children }: { children: ReactNode }) {
  const [me, setMe] = useState<MeDto | null>(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    payrollApi.getMe()
      .then((result) => setMe(result))
      .catch(() => setMe(null))
      .finally(() => setLoading(false));
  }, []);

  const signOut = useCallback(() => {
    setMe(null);
    // Clear token from storage — adjust to match existing auth client
    localStorage.removeItem("access_token");
  }, []);

  const value = useMemo(() => ({ me, loading, signOut }), [me, loading, signOut]);

  return <AuthContext.Provider value={value}>{children}</AuthContext.Provider>;
}

function useAuthContext(): AuthContextValue {
  const ctx = useContext(AuthContext);
  if (!ctx) throw new Error("useAuthContext must be used within AuthProvider");
  return ctx;
}

export { AuthProvider, useAuthContext };
export type { AuthContextValue, MeDto };

                </div>
              )}

          </Card>
        </button>
      ))}
    </div>
  );

interface SparkLineProps {
  data: Array<{ sen: number }>;
  color: string;
}

function SparkLine({ data, color }: SparkLineProps) {
  if (data.length < 2) return null;
  const max = Math.max(...data.map((d) => d.sen));
  const min = Math.min(...data.map((d) => d.sen));
  const range = max - min || 1;
  const W = 100;
  const H = 32;
  const pts = data.map((d, i) => {
    const x = (i / (data.length - 1)) * W;
    const y = H - ((d.sen - min) / range) * H;
    return `${x},${y}`;
  });
  return (
    <svg className="w-full h-full" viewBox={`0 0 ${W} ${H}`} preserveAspectRatio="none">
      <polyline fill="none" stroke={color} strokeWidth="1.5" points={pts.join(" ")} />
    </svg>
  );
}

import { useCallback, useEffect, useState } from "react";
import { useParams } from "wouter";
import { RunHeader } from "./run-header";
import { TotalsStrip } from "./totals-strip";
import { EmployeeGrid } from "./employee-grid";
import { EmployeeSlideOver } from "./employee-slide-over";
import type { EmployeeLineDto, PayRunWorkspaceView } from "@/web/api/payroll-api";
import { payrollApi } from "@/web/api/payroll-api";
import type { RunStatus } from "@/components/payroll/status-badge";

function WorkspacePage() {
  const { runId } = useParams<{ runId: string }>();
  const [view, setView] = useState<PayRunWorkspaceView | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);
  const [activeTab, setActiveTab] = useState<"this-run" | "compare" | "history">("this-run");
  const [slideOver, setSlideOver] = useState<{
    open: boolean;
    employeeId: string | null;
    tab: "line" | "payslip" | "derivation";
  }>({ open: false, employeeId: null, tab: "line" });

  const reload = useCallback(async () => {
    if (!runId) return;
    setLoading(true);
    setError(null);
    try {
      const v = await payrollApi.getWorkspace(runId);
      setView(v);
    } catch (e) {
      setError("Failed to load workspace");
    } finally {
      setLoading(false);
    }
  }, [runId]);

  useEffect(() => { reload(); }, [reload]);

  const openSlideOver = (employeeId: string, tab: "line" | "payslip" | "derivation") => {
    setSlideOver({ open: true, employeeId, tab });
  };

  const activeLine: EmployeeLineDto | null =
    view?.lines.find((l) => l.employeeId === slideOver.employeeId) ?? null;

  if (loading) {
    return <div className="flex items-center justify-center h-64 text-muted-foreground text-sm">Loading…</div>;
  }

  if (error || !view) {
    return <div className="flex items-center justify-center h-64 text-destructive text-sm">{error ?? "Not found"}</div>;
  }

  return (
    <div className="flex flex-col gap-4 -m-6">
      <RunHeader
        activeTab={activeTab}
        onApprove={() => payrollApi.approve(runId).then(reload)}
        onRecompute={() => payrollApi.recompute(runId).then(reload)}
        onReview={() => payrollApi.review(runId).then(reload)}
        onTabChange={setActiveTab}
        view={view}
      />

      <div className="px-6 flex flex-col gap-4">
        <TotalsStrip tiles={view.totals} />

        <EmployeeGrid
          lines={view.lines}
          onEditLine={(id) => openSlideOver(id, "line")}
          onViewDerivation={(id) => openSlideOver(id, "derivation")}
          onViewFindings={(id) => openSlideOver(id, "derivation")}
          onViewPayslip={(id) => openSlideOver(id, "payslip")}
        />
      </div>

      <EmployeeSlideOver
        initialTab={slideOver.tab}
        line={activeLine}
        onClose={() => setSlideOver((s) => ({ ...s, open: false }))}
        open={slideOver.open}
        runStatus={view.run.status as RunStatus}
      />
    </div>
  );
}

import type { EmployeeSummary } from "@/web/api/payroll-api";
import { payrollApi } from "@/web/api/payroll-api";
import { useScopeContext } from "@/web/context/scope-context";
import { EmployeeImportPanel } from "@/web/employee-import-panel";

function EmployeesPage() {
  const { scope } = useScopeContext();
  const [employees, setEmployees] = useState<EmployeeSummary[]>([]);
  const [search, setSearch] = useState("");
  const [loading, setLoading] = useState(true);

  const companyId =
    scope.mode === "selected" && scope.companyIds.length === 1
      ? scope.companyIds[0]
      : undefined;

  useEffect(() => {
    setLoading(true);
    payrollApi.getEmployees({ companyId })
      .then(setEmployees)
      .finally(() => setLoading(false));
  }, [companyId]);

  const filtered = search
    ? employees.filter(
        (e) =>
          e.name.toLowerCase().includes(search.toLowerCase()) ||
          e.code.toLowerCase().includes(search.toLowerCase())
      )
    : employees;

  return (
    <div className="flex flex-col gap-6">
      <Card>
        <CardHeader className="flex-row items-center justify-between">
          <CardTitle>Employees</CardTitle>
          <Input
            className="w-60"
            onChange={(e) => setSearch(e.target.value)}
            placeholder="Search by name or code…"
            value={search}
          />
        </CardHeader>
        <CardContent>
          {!loading && filtered.length === 0 ? (
            <EmptyState
              description="No employees found. Import employees below to get started."
              icon={<UsersIcon />}
              title="No employees"
            />
          ) : (
            <Table>
              <TableHeader>
                <TableRow>
                  <TableHead>Code</TableHead>
                  <TableHead>Name</TableHead>
                  <TableHead>Company</TableHead>
                  <TableHead>Status</TableHead>
                </TableRow>
              </TableHeader>
              <TableBody>
                {filtered.map((emp) => (
                  <TableRow key={emp.id}>
                    <TableCell className="font-mono text-xs text-muted-foreground">
                      {emp.code}
                    </TableCell>
                    <TableCell className="font-medium">{emp.name}</TableCell>
                    <TableCell className="text-sm text-muted-foreground">{emp.companyId}</TableCell>
                    <TableCell>
                      <Badge variant="secondary">{emp.status}</Badge>
                    </TableCell>
                  </TableRow>
                ))}
              </TableBody>
            </Table>
          )}
        </CardContent>
      </Card>

      <Separator />

      <EmployeeImportPanel onImportComplete={() => {
        payrollApi.getEmployees({ companyId }).then(setEmployees);
      }} />
    </div>
  );
}

export { EmployeesPage };
```

Note: `EmployeeImportPanel` may need a prop `onImportComplete` — add it to the existing panel if missing.
